# Goal Runs

Create one Markdown record per autonomous goal from
`../skills/lightflux-autopilot/assets/goal-run-template.md`.

Goal records are the auditable execution history. Keep source locators,
acceptance criteria, decisions, attempts, changed files, verification evidence,
and deferred work current throughout the run. Do not store credentials,
personal task content, or raw private API responses.

Use `YYYY-MM-DD-<goal-slug>.md` names. Do not reuse an old record for a new
goal.
