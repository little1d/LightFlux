# LightFlux 1.1.3：小光 AI 对话

## 新增

- 新增 AI 助手「小光」（Xiaoguang），独立对话页支持新建多个会话、切换、重命名和删除。
- 流式回复，支持 Markdown 列表、表格与代码块；可停止生成、重试未完成的回复、复制回复。
- 对话页内配置模型：OpenAI、DeepSeek 或自定义 OpenAI Chat Completions 兼容服务，可填写服务地址、模型和自己的 API Key。
- 支持手动测试连接、替换和移除密钥，以及无效密钥、额度不足、网络中断等错误提示。
- 小光可查询任务和项目，并可创建任务、修改标题/日期/优先级/项目、完成或重新打开任务、移入回收站、恢复以及直接永久删除任务。
- 任务写操作先显示实际预览，确认并安全保存后才执行；执行结果支持撤销。查询结果先在本地展示，允许后才发送给模型。
- 桌面端首次从系统凭据库读取模型密钥后会在当前进程内复用，避免一次对话或工具操作反复弹出钥匙串授权。
- 对话页适配窄窗口，中英文界面，支持 Enter 发送、Shift + Enter 换行。

## 开始使用

1. 打开侧栏的「小光」，点击「配置模型」或右上角的「模型配置」。
2. 选择服务商，填写模型名称、服务地址与 API Key，点击「保存配置」。
3. 可点击「测试连接」发送一条简短测试消息。模型服务的费用由用户自己的账户承担。
4. 点击「返回对话」或按 Escape 开始聊天，当前会话和聊天草稿会保留。新建会话后，每个会话独立保留历史记录。

服务地址默认填基础 URL，例如 `https://api.openai.com/v1`，请求时追加
`/chat/completions`。如果服务商给出完整请求地址，在自定义配置中选择
「完整接口地址」，按填写的地址发送请求。两种方式均使用 Chat Completions
请求格式和 SSE 流式回复。远程服务使用 HTTPS，本地模型可使用
`http://127.0.0.1:端口/v1`。

## 本地桌面调试

在仓库根目录执行：

```bash
cd lightflux
npm run desktop:dev
```

命令会启动本地前端和「LightFlux Dev」桌面窗口，无需安装，可与已有稳定版
同时运行。开发版使用独立应用标识、数据目录和密钥，不覆盖稳定版。
修改界面后支持热更新，首次启动需要编译 Rust。
模型请求由桌面原生网络层发送，不受浏览器 CORS 预检限制。
在窗口内进入「小光 → 模型配置」填写并保存配置，即可测试连接。
Web 预览、开发版和稳定版使用各自的存储，首次在开发版测试需重新填写 API Key。

macOS 开发数据位于
`~/Library/Application Support/com.little1d.lightflux.dev/`。
请使用上述命令；直接运行未加开发配置的 `npx tauri dev` 会复用稳定版标识，
可能被单实例机制转回稳定版。

开发启动与桌面导出均忽略 dotenv 和旧云服务环境变量，不依赖托管服务。

## 数据与范围

- 桌面端密钥保存在系统凭据库，不写入会话、任务文件或备份。移除密钥不会删除会话。
- 桌面端会话独立保存在应用数据目录下的 `chat-v1.json`，替换前保留
  `chat-v1.backup.json`。当前设置中的任务备份仍只包含 V12 任务数据，不包含对话；
  备份对话时需同时保留这两个文件。
- Web 仅用于本地预览：对话使用 IndexedDB，密钥只保留在当前浏览器会话中。
  直接访问模型服务需要服务商允许 CORS。
- 旧版 Agent 会话会导入为一个会话，保留迁移源和失败回复；不执行其中的历史操作建议。
- 模型只接收当前会话最近的消息，以及用户明确允许发送的工具结果；不会自动读取
  任务或工作区。任务操作复用桌面端与 CLI 的本地业务规则，不安装或启动 CLI，
  也不允许模型执行 shell 命令或任意本地接口。
- 写操作使用版本检查、固定幂等键、审计和最新操作撤销。只有持久化成功后才向模型
  返回成功；同名目标不明确、预览过期或任务已被继续修改时停止执行。
- 永久删除不会先进入回收站，确认卡会明确列出受影响的任务分支；最新且未被继续修改
  的删除操作仍可撤销。
- 保存失败时保留窗口内内容并提示重试；无法安全读取记录时停止写入。
