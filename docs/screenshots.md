# 功能一览

下面的截图来自 `main` 分支当前的真实 Web 构建（`lightflux/dist`），
用示例数据填充，没有手工修图。

## 今日

今日列表把当天的任务、子任务和今天到期的 Milestone 放在同一屏。
左侧是导航栏，右侧内容区会随窗口宽度自适应；窗口变窄时自动切换成移动端布局。

![今日列表](/shots/today.png)

## 任务详情

点开任意一条任务，右侧会展开详情面板：正文支持标题、列表与图片，
上方可以直接改日期、时间、Project、优先级和关联的 Milestone。

![任务详情](/shots/editor.png)

## 日历

月视图里每天会显示当天任务的所属 Project 颜色；下方列出所选日期的任务，
可以直接勾选完成或拖到别处。

![日历视图](/shots/calendar.png)

## Milestone

公历生日、纪念日、农历节日和自定义倒数日都可以放进同一个列表。
卡片直接显示「今天」「还有 N 天」或「已过去 N 天」。

![Milestone 列表](/shots/milestones.png)

## 统计

所有数字来自 `TaskEvent`：完成数、计划完成率、待办净变化和延期情况。
没有历史数据时它会如实说「暂无可对照数据」，而不是猜一个数字。

![统计视图](/shots/statistics.png)

## Project

每个 Project 显示自己的完成进度；删除 Project 会把任务退回收件箱，而不是一起删掉。

![Project 列表](/shots/projects.png)

## 完成记录

已完成的任务按日期分组，可以随时重新打开或移入回收站。

![完成记录](/shots/completed.png)

## 小光 AI

多会话对话页，可以查询和修改任务。任务写操作先展示预览，确认并安全保存后才执行，
执行结果支持撤销。模型由你自己配置，密钥存在系统凭据库。

![小光 AI](/shots/chat.png)
